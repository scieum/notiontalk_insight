# notion-publish (A7, B3, B7)

> 상태: **미구현 (V3, V5 예정)**. 설계서 §2.4 A7, §2.5 B3/B7.

## 목적

노션 API 호출을 전담하는 유일한 스킬. 발행(A7)·질문 폴링(B3)·답변 기입(B7) 세 방향
모두 이 스킬을 거친다.

## A7 — 발행

- FAQ/팁/결정·액션 → 각 DB에 `자동생성` 태그로 생성, 또는 기존 페이지에 근거 추가(병합)
- 리포트 → 리포트 DB에 `초안` 상태로 생성 (**자동으로 `발행` 상태를 만들지 않는다** — G-R은 사람만)

## B3 — 질문함 폴링 (30분 간격)

- `상태 = 대기`인 행 조회 → `/output/questions/<id>.json` 저장, 노션 상태 → `처리중`
- 질문 본문 < 5자면 상태 `확인필요` + 사유 기입

## B7 — 답변 기입

- 검증 통과 답변을 `답변` 속성에 기입, 상태 `답변완료`, `자동생성` 태그, 출처 링크 블록
- 중복 생성 방지: `/output/answers/<id>.json` 존재 시 생성 단계 스킵

## 스크립트

| 스크립트 | 역할 | 상태 |
|---------|------|------|
| `scripts/publish.py` | A7 노션 DB 발행 | 미구현 |
| `scripts/poll_questions.py` | B3 질문함 폴링 | 미구현 |
| `scripts/write_answer.py` | B7 답변 기입 | 미구현 |

## 성공 기준 / 실패 처리

CLAUDE.md §5 표의 A7, B3, B7 행 참조. API 429/5xx → 지수 백오프 3회 → 지속 실패 시
manifest에 `pending` 기록 후 다음 사이클 재시도. 리포트 발행 실패는 에스컬레이션.
