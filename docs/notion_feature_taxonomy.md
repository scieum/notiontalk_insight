# 노션 기능 분류표 (notion_feature_taxonomy.md)

> A4(팁 카드 태깅)에서 LLM이 선택하는 태그 목록. 팁 카드는 반드시 이 목록 중
> 하나 이상을 `feature_tags`로 붙인다. 목록에 없는 새 태그가 필요하다고
> 판단되면 임의로 만들지 말고 에스컬레이션으로 운영자에게 추가를 요청한다.

| 태그 | 설명 |
