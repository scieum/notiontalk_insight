## 운영 메모 (프롬프트에 들어가지 않음)

- **방 이름 끝의 😉 는 방 이름의 일부다** (2026-08-26 운영자 확인). A0'(kakao-export)의
  JXA가 채팅방을 고를 때 이 이모지까지 포함해 정확히 일치시켜야 한다. 이모지를 떼거나
  부분 일치로 찾으면 다른 방을 열 위험이 있다 — 다른 방 데이터는 어떤 파일에도
  남기면 안 된다(R5). 코드 안에 하드코딩하지 말고 이 파일에서 읽어 쓴다.
- 카카오톡 DB 내 방 식별자: 미정 (§6 O1' — A0 경로를 쓰게 되면 그때 기입.
  현재 `risk_acceptance.md`가 `미승인`이라 A0는 착수하지 않았다).
- **아직 안 채워진 것**: 방 성격/톤, 상용어, 운영진 닉네임, 특이사항. 이 넷은
  A4 인사이트 품질에 직접 영향을 준다 — 특히 상용어 표가 비어 있으면 방에서만
  통하는 줄임말을 LLM이 엉뚱하게 해석한다.
