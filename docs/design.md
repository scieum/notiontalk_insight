# 리포트 디자인 시스템 (design.md)

> 주간 리포트 화면의 시각 언어를 정의한다. 무엇을 어떤 순서로 싣는지는
> [report_format.md](report_format.md)에, 어떻게 보이는지는 이 문서에 있다.
> 구현은 [scripts/render_report.py](../scripts/render_report.py)의 `CSS` 상수 하나다.
>
> 방향은 2026-08-26 운영자가 지정한 [huddling.ai AI Report](https://huddling.ai/ai-report/2)
> 기조를 따른다. 실제 페이지에서 확인한 값을 근거로 잡았다.

---

## 1. 기조

거의 검정에 가까운 **차가운 회보라 바탕**에, **파랑 하나**로만 강조한다. 색을 여러 개
쓰지 않는다 — 강조가 두 개 이상이면 어느 것도 강조가 아니다.

huddling 실측:

| 역할 | huddling 값 |
|------|------------|
| 가장 어두운 바탕 | `#050510` |
| 면 | `#14141F`, `#1B1B26` |
| 파랑 섞인 강조 면 | `#1B2440` |
| 경계 | `#2A2A38` |
| 본문 | `#E8E8EE` |
| 흐린 글자 | `#B9B9C4`, `#8B8B98`, `#7C7C8A` |
| 액센트 | `#7AA2FF` (밝은), `#0058E0` (진한) |
| 라운드 | 6~16px (주로 8·10·12) |
| 글꼴 | Pretendard Variable |

## 2. 토큰

**다크가 기본 정체성이다.** 그래서 `:root`에 다크를 두고 밝은 테마를 얹는다.
테마는 3상태를 모두 지원한다 — 시스템 설정, 명시적 라이트, 명시적 다크.

```
:root                                              다크 (기본)
@media (prefers-color-scheme: light)
  :root:not([data-theme="dark"])                   시스템이 밝음
:root[data-theme="light"]                          사용자가 밝음을 선택
```

| 토큰 | 다크 | 라이트 | 쓰임 |
|------|------|--------|------|
| `--bg` | `#050510` | `#FFFFFF` | 페이지 바탕 |
| `--surface` | `#14141F` | `#F7F7FA` | 카드·판권 |
| `--surface-2` | `#1B1B26` | `#F2F2F7` | 칩·코드 |
| `--tint` | `#1B2440` | `#EDF2FF` | 실무 팁 패널·배지 |
| `--border` | `#2A2A38` | `#DCDCE6` | 또렷한 경계 |
| `--border-soft` | `#1F1F2B` | `#E8E8EE` | 카드 경계 |
| `--text` | `#E8E8EE` | `#14141F` | 본문 |
| `--text-2` | `#B9B9C4` | `#4A4A5A` | 보조 본문 |
| `--text-3` | `#8B8B98` | `#7C7C8A` | 라벨·메타 |
| `--accent` | `#7AA2FF` | `#0058E0` | 액센트 |
| `--on-accent` | `#050510` | `#FFFFFF` | 액센트 위 글자 |

**규칙 두 가지.** 지키지 않으면 한쪽 테마에서 글자가 안 보인다.

1. 색은 `:root` 계열 블록에서만 정의한다. 컴포넌트 규칙 안에 특정 테마 전용 색을
   직접 쓰지 않는다.
2. 테마 블록 안에는 **토큰 재정의만** 넣는다. 레이아웃·타이포 규칙을 넣지 않는다.

## 3. 타이포그래피

**Pretendard 하나만 쓴다.** 서체를 바꿔 위계를 만들지 않고 가변 굵기축으로 만든다.

| 역할 | 크기 | 굵기 | 자간 |
|------|------|------|------|
| 리포트 제목 | `clamp(1.9rem, 5.4vw, 3rem)` | 700 | `-.033em` |
| 섹션 제목 | `clamp(1.3rem, 3vw, 1.6rem)` | 700 | `-.028em` |
| 항목 제목 | 1.0625rem | 600 | `-.022em` |
| 본문 | .9375rem | 400 | 기본 |
| 영문 라벨 | .6875rem | 600 | `.18em` + 대문자 |

- 한글은 `word-break: keep-all`로 낱말이 쪼개지지 않게 한다. 대신 긴 URL을 위해
  `overflow-wrap: anywhere`를 함께 둔다.
- 숫자가 세로로 늘어서는 곳(통계·판권)은 `font-variant-numeric: tabular-nums`.
- Pretendard는 Google Fonts에 없고 아티팩트 CSP가 외부 호스트를 막는다. 그래서
  **그 호에 실제로 쓰인 글자만 서브셋해 data URI로 심는다** — 전체 2.0MB가 실측
  139KB가 된다. 서브셋은 `render_report.py`의 `subset_font()`가 한다(fonttools 필요).

## 4. 레이아웃

- 한 컬럼, 최대 `52rem`. 본문 줄길이를 읽기 좋은 범위로 묶는다.
- 섹션마다 `영문 라벨 → 한글 제목 → 고정 설명문 → 내용`. 라벨만 액센트 색이다.
- 항목은 **카드**다: `--surface` 바탕 + `--border-soft` 경계 + 라운드 10~12px.
- 실무 팁은 카드 안의 `--tint` 패널로 구분한다. 형광펜 같은 배경 강조는 쓰지 않는다.
- 목록 마커는 액센트색 도형이다: 미해결은 빈 원, 액션은 빈 사각형, CTA는 화살표.
  마커가 의미를 담아야 하고 장식이면 뺀다.

### 그리드 주의 (실제로 깨졌던 부분)

`li`를 2열 그리드로 잡고 `::before`로 번호를 넣으면 **그리드 항목이 셋이 된다**
(`::before`, `h3`, `p`). 그러면 `p`가 좁은 번호 칸으로 밀려 본문이 한 단어씩
줄바꿈된다. 번호는 별도 요소(`.t-num`)로 넣고 본문은 래퍼(`.t-body`)로 묶는다.

## 5. 쓰지 않는 것

- 두 번째 액센트 색. 경고·위험을 위한 빨강도 쓰지 않는다 — 리포트는 경보가 아니다.
- 형광펜 배경, 그라디언트 히어로, 이모지 섹션 마커.
- 서체 두 종 이상. 세리프 제목도 쓰지 않는다.
- 애니메이션. 읽는 문서라 움직일 이유가 없다.
- 외부 리소스 일체(CSP가 막는다). 이미지가 필요하면 인라인 SVG나 data URI로.

## 6. 로고

방 로고(노션 블록 마크)는 인라인 SVG로 그려 `render_report.py`의 `LOGO_SVG`에 있으나
**현재 렌더링하지 않는다**(2026-08-26 운영자 요청). 다시 넣으려면 머리말 `.kicker`와
판권 `.sec-label`에 끼운다.

## 7. 검토 중 가명 확인

리포트를 검토하다 "함께한 선생님G가 누구지?"를 확인해야 하면:

```
python3 scripts/whois.py --draft output/insights/period_<id>.draft.json "함께한 선생님G"
python3 scripts/whois.py --draft ... --all          # 전체 대응
```

대응표는 **파일로 저장하지 않는다** — 그 파일 자체가 재식별 열쇠다(C2, R4).
A6와 같은 방식으로 그때그때 다시 계산하므로 같은 범위면 항상 같은 결과가 나온다.
