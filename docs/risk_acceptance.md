## 인지한 리스크 (설계서 §1.6)

| 리스크 | 내용 |
|--------|------|
| R1 약관 | 카카오 서비스 약관상 리버스 엔지니어링·비공식 접근 금지 조항에 해당할 수 있음. 계정 제재 가능성은 낮으나 0은 아님 |
| R2 취약성 | 카카오톡 앱 업데이트 한 번에 복호화 로직·스키마가 깨질 수 있음 |
| R3 참조 구현 신뢰성 | 복호화 방법의 출처가 분산되어 있고 유지보수가 불확실함 |
| R4 키 자료 | 복호화에 기기·계정 고유값이 필요할 수 있음 |
| R5 개인정보 노출 면적 확대 | DB에는 대상 방 외 모든 대화가 저장되어 있음 |

## 완화책 (요약)

- 읽기 전용(C1), 서버 미전송, 결과물은 요약·재구성만 하고 원문 재배포 없음
- 스키마 지문 검증 + 자동 폴백(C1', C7)
- 참조 구현 출처는 [db_access_reference.md](db_access_reference.md)에 별도 기록
- 키 자료는 Keychain/.env에만, 로그·산출물에 절대 기록하지 않음
- 대상 방 ID로 필터한 결과만 추출, 복사본은 즉시 삭제, 다른 방 데이터 미보존
