이번 주는 노션 AI와 챗GPT·클로드·코덱스를 조합해 쓰는 법에 대한 이야기가 많았습니다. 요금제별 차이와 MCP 연동 팁이 활발히 오갔습니다.

이번 주 주요 주제

이번 주 오픈채팅방에서 가장 많이 오간 이야기입니다.

  1. 노션AI와 외부 AI(챗GPT·클로드·코덱스)의 역할 분담

    DB 작업은 노션AI로, 외부 산출물은 코덱스·클로드로 나누는 사례와 토큰 소모 차이 논의가 길게 이어졌습니다.

  2. 노션 요금제별 AI 기능 차이

    플러스와 비즈니스 요금제의 AI 사용량·기능 차이를 묻는 질문과 비즈니스 종료 후 대안 모색이 반복됐습니다.

  3. MCP를 통한 노션-AI 연동 방법

    챗GPT·클로드·코덱스 각각에서 MCP로 노션을 연결하는 방법과 비용 구조가 여러 타래에서 공유됐습니다.

  4. DB 설계를 AI에게 맡기는 방식

    관계형 속성과 롤업까지 AI가 처리할 수 있게 되면서 일단 대충 만들고 다듬는 접근이 공유됐습니다.

  5. 학교 축제 준비(인생네컷) 관련 정보 공유

    업체 추천과 바이브코딩으로 만든 웹앱 소스 공유가 함께 이뤄졌습니다.

해결된 질문

질문과, 오픈채팅방에서 실제로 채택된 답을 옮겼습니다.

노션 플러스 요금제와 비즈니스 요금제의 차이는 무엇인가요?

비즈니스 요금제부터 노션 AI 에이전트를 쓸 수 있고, AI가 페이지·데이터베이스를 읽고 쓸 수 있습니다. 회의 전사·요약을 해주는 AI 노트 기능도 추가됩니다. 데이터베이스 권한 관리, 폼 조건부 질문 등도 더 세밀해집니다. 플러스 요금제는 AI를 체험용으로 약 10회만 쓸 수 있습니다.

이렇게 써보세요플러스 요금제의 노션 AI는 체험용으로 약 10회만 쓸 수 있습니다.

AI기타

헤르메스나 오픈클로 같은 용어를 몰라도 괜찮은가요?

전혀 부끄러운 일이 아니며, 챗GPT나 클로드의 기본 채팅 기능과 워크 모드만으로도 웬만한 작업은 처리할 수 있습니다.

이렇게 써보세요새로운 AI 도구를 몰라도 챗GPT·클로드 기본 기능으로 대부분 작업이 가능합니다.

AI

챗GPT·클로드에 노션 커넥터를 연결해 쓰려면 비용은 어떻게 되나요?

챗GPT와 클로드 모두 노션 커넥터 연결이 가능하지만 20달러 상당의 유료 플랜이 필요합니다. 편의성과 비용을 비교해 결정하면 됩니다.

이렇게 써보세요노션 연동 편의성이 20달러 가치만큼 크다고 느껴지면 가입을 고려해보세요.

임베드·연동AI

노션AI, 클로드, GPT 20$ 요금제 기준으로 같은 모델을 쓸 때 사용 가능한 토큰(한도)이 비슷한가요?

공식적으로 발표된 자료는 없지만, 1000쌤의 추정으로는 노션 비즈니스 $20 요금제에는 비즈니스 플랜 특화 기능 비용과 에이전트 호출 비용이 함께 포함되어 있어, 동일 모델이라도 노션에서 호출할 때 사용량이 클로드 등에서 직접 호출할 때보다 적을 수밖에 없다고 봅니다. 특정 기업의 특정 모델을 많이 쓰고 싶다면 해당 사 요금제를 구독하는 것이 낫고, 노션의 AI노트·에이전트가 매력적이라면 비즈니스 요금제를 유지하며 저가/고가 모델을 혼합해 쓰는 것을 추천합니다.

이렇게 써보세요특정 모델을 집중적으로 쓸 거면 노션보다 해당 사 요금제 직접 구독이 유리합니다.

AI

클로드 20$ 요금제에 노션을 연결해서 쓰면 노션AI처럼 페이지 생성 등 기존 작업이 다 가능한가요?

1000쌤 답변으로 전부 가능합니다. 다만 사용감 차이가 있는데, 노션에서는 @ 멘션 한 번으로 페이지·DB를 참조시킬 수 있지만 클로드나 GPT에서는 페이지 링크나 페이지 ID를 직접 제공하는 것이 좋습니다(이름으로 탐색하게 하면 유사 페이지를 잘못 찾을 수 있음).

이렇게 써보세요클로드에 노션 페이지를 참조시킬 땐 이름 대신 페이지 링크/ID를 주는 것이 안전합니다.

AI임베드·연동

학교 축제에서 쓸 인생네컷 사진 부스 대여 업체를 추천받을 수 있나요?

심플큐브가 괜찮다는 의견이 있었고, 대부분 업체가 전국 출장이 가능해 지역은 크게 상관없다는 답변을 받았습니다. 네이버에서 추천 높은 순으로 찾아보는 것도 추천됐습니다.

이렇게 써보세요인생네컷 업체는 대부분 전국 출장이 가능해 지역 무관하게 알아봐도 됩니다.

AIEDAP 마스터교원 연수가 추후 활용도가 높은 편인가요?

본인이 얼마나 적극적으로 활동하는지에 따라 달라지고, 서울대에서 주도하는 활동이 많아 유리한 편이라는 의견이 있었습니다. 다른 선생님은 선도교사 연수 자체는 기대만큼 유익하지 않았고, 같은 조 선생님들과의 활용사례 공유가 더 도움이 됐다는 경험을 전했습니다.

노션 MCP를 사용하는 데 비용이 들거나 제약이 있나요?

노션 MCP 자체는 무료지만 MCP 서버와 연결하려면 GPT나 Claude 구독이 필요합니다. 페이지별 권한 설정만 잘 하면 미세한 블록 조정 외에는 몸으로 느낄 만한 제약은 크게 없다는 답변이었습니다.

이렇게 써보세요노션 MCP는 무료지만 GPT나 Claude 구독료는 별도로 필요합니다.

아직 답이 없는 질문

답이 달리지 않은 질문입니다. 아시는 분은 오픈채팅방에 남겨주세요.

  • 노션 데이터베이스가 뜨지 않는다는 문제가 실제 장애였는지 확인되지 않았습니다.
  • AIEDAP 마스터교원 연수가 활용도 면에서 좋은 선택인지에 대한 의견이 엇갈렸습니다.
  • SW·AI 하네스 엔지니어링, 에이전트, 바이브코딩 관련 책 추천 요청에 답이 없었습니다.
  • 노션 요금제의 원화 결제와 달러 결제 간 금액 차이 여부가 확인되지 않았습니다.
  • 졸업생 계정의 2차인증 메일이 삭제되어 새 기기 로그인 인증을 받을 방법이 확인되지 않았습니다.
  • 비즈니스 요금제 종료 후 저렴하게 노션 AI처럼 쓸 수 있는 방법에 대한 확정 답이 없었습니다.
  • 헤르메스가 무엇인지 명확한 정의는 나오지 않았습니다.
  • 업무포털 사용 중 윈도우 클립보드(win+V) 단축키가 안 되는 문제의 해결법
  • 닷(Dot)과 어사이드(Aside)의 차이점
  • 유료/무료 워크스페이스에 따라 사이드메뉴 선택탭 위치가 다른 이유

노션 AI 에이전트에 챗GPT 유료 플랜 연결 가능

비즈니스 플랜 이상에서는 노션 AI 에이전트에 챗GPT 유료 플랜을 연결해 쓸 수 있게 되었습니다. 노션 AI 사용량 한도가 부족했던 경우 대안이 될 수 있습니다.

이렇게 써보세요비즈니스 플랜이면 챗GPT 유료 플랜을 노션 AI 에이전트에 연결해보세요.

AI로 데이터베이스 설계하기

복잡하지 않은 구조라면 AI에게 대충 만들게 한 뒤 손보는 방식이 빠릅니다. 정교한 구조가 필요한 경우에도 계획을 잘 잡아두면 AI가 관계형 연결을 빠르게 해줍니다.

이렇게 써보세요단순한 DB는 AI에게 대충 만들게 한 뒤 손보는 게 빠릅니다.

노션 AI의 롤업·버튼 자동 생성 지원 현황

노션 AI가 이제 롤업 속성도 만들어줄 수 있게 되었습니다. 다만 버튼 블록과 버튼 속성은 아직 AI가 자동으로 만들어주지 못합니다.

이렇게 써보세요노션 AI는 롤업은 생성 가능하지만 버튼은 아직 지원하지 않습니다.

기타3

경기도교육청 학교생활기록부 작성 도우미 프로그램 공유

2026 학교업무지원자동화프로그램(HTML전용) 보급 공지 링크가 공유되었습니다.

축제 사진 부스를 외부 대여 대신 동아리 자체 제작으로 해결하는 아이디어

시간 여유가 있다면 관련 동아리 학생들이 바이브코딩으로 인생네컷 형식의 웹앱을 직접 개발·테스트해 축제에 쓰는 방법도 제안됐습니다. 동아리 활동으로 연계할 수 있다는 의견입니다.

학교용으로 제작한 인생네컷 웹앱 코드를 깃허브에 공유

케미가 체질(하연T)이 자신의 학교용으로 제작했던 인생네컷 웹앱 코드를 깃허브 링크로 공유했습니다. 바이브코딩에 관심이 있으면 해당 코드를 가져가 직접 작업해볼 수 있다고 안내했습니다.

이렇게 써보세요바이브코딩에 관심있다면 공유된 깃허브 코드를 가져가 직접 커스터마이징해볼 수 있습니다.

임베드·연동3

코덱스에서도 MCP로 노션 연결 가능

코덱스에서 MCP로 노션을 연결하면 노션 비즈니스 플랜에서 쓰는 기능들을 거의 다 활용할 수 있습니다.

이렇게 써보세요코덱스를 쓴다면 MCP로 노션을 연결해 비즈니스 기능을 그대로 활용해보세요.

챗GPT에 노션 같은 블록 에디터 '스페이스' 메뉴 등장

챗GPT 안에 스페이스라는 메뉴가 생겨 페이지를 생성하고 노션 같은 블록 에디터로 간단한 작업을 할 수 있지만, 노션을 대체할 수준은 아닙니다.

노션 MCP 플러그인으로 챗GPT 채팅창에서 노션 작업

노션 MCP 플러그인을 설치하면 챗GPT 채팅창에서도 노션 작업이 가능합니다.

이렇게 써보세요노션 MCP 플러그인을 설치하면 챗GPT 채팅창에서 노션 작업을 해볼 수 있습니다.
