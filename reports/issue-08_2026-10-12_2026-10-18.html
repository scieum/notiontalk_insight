이번 주 주요 주제

이번 주 오픈채팅방에서 가장 많이 오간 이야기입니다.

  1. 노션 교육용 요금제 핫딜가와 졸업생 계정 이슈

    핫딜가 유지 기한, 이메일 변경 시 할인 해제, 삭제된 계정 처리까지 여러 질문이 이어졌습니다.

  2. 노션 버튼으로 AI 에이전트 호출하기

    버튼 블록과 데이터베이스 버튼 속성에 프롬프트를 넣어 기본 에이전트를 바로 부르는 활용법이 공유됐습니다.

  3. 캘린더 보기에서 여러 날 일정 필터링

    기본 '이번 일' 필터로는 중간 날짜가 빠지는 문제를 고급 필터로 해결하는 방법이 다뤄졌습니다.

  4. 노션톡 라이브챌린지 신설

    무료 라이브 클래스와 유료 빌드 챌린지로 구성된 새 프로그램이 투표를 거쳐 확정됐습니다.

  5. 데이터베이스-탈리 연결 방식

    인라인 상태에서는 연결 버튼이 보이지 않아 혼란이 있었고, 페이지 단위 연결 원리가 설명됐습니다.

Solved4

해결된 질문

질문과, 오픈채팅방에서 실제로 채택된 답을 옮겼습니다.

대학원 이메일 계정이 이미 삭제됐는데 노션은 그 이메일로 계속 쓰고 있다면 문제가 될까요?

당장은 문제가 없지만, 이메일 변경이나 인증 재요청이 필요해지면 기존 이메일로 인증 메일을 받을 수 없어 곤란해질 수 있습니다. 이런 경우 지원팀에 문의하면 방법을 찾을 수 있습니다.

이렇게 써보세요삭제된 이메일을 계속 쓰고 있다면 미리 지원팀에 문의해두는 것이 안전합니다.

데이터베이스를 탈리와 연결하려는데 인라인 상태에서는 연결 버튼이 안 보입니다. 페이지로 바꿔야만 연결되나요?

연결은 페이지 단위로 이루어지므로 해당 페이지에 들어가서 연결해야 합니다. 상위 페이지의 연결 상태가 하위에 상속되므로, 상위 페이지를 연결하면 인라인 데이터베이스도 함께 연결됩니다. 연결 후 다시 인라인으로 되돌려도 연결은 유지됩니다.

이렇게 써보세요탈리 연결은 상위 페이지에서 한 번만 해두면 하위 인라인 데이터베이스까지 이어집니다.

데이터베이스임베드·연동

캘린더 보기에서 필터를 '이번 일'로 설정하면, 여러 날에 걸친 일정(시작일~종료일)이 시작일에만 뜨고 중간 날짜에는 안 뜹니다. 어떻게 고치나요?

고급 필터로 들어가서 '종료일은 오늘 이후, 시작일은 오늘 이전' 조건으로 설정하면 됩니다. 두 조건 모두 당일을 포함하도록 설정해야 놓치는 날짜 없이 잡힙니다.

이렇게 써보세요여러 날 일정은 기본 '이번 일' 필터 대신 고급 필터의 시작일/종료일 조건으로 걸러야 합니다.

데이터베이스

교원대 졸업생 구글 계정이 삭제되면 그 계정으로 쓰던 노션 계정은 어떻게 하나요?

노션 설정의 이메일 변경 메뉴에서 기본 이메일을 바꾸면 해결됩니다.

이렇게 써보세요설정 - 이메일 변경에서 기본 이메일을 바꾸면 계정이 유지됩니다.

기타2

비즈니스 요금제 기본 이메일 변경 시 교육요금제 할인 해제 주의

함께한 선생님G이 개인 이메일로 기본 이메일을 바꾸자 교육요금제가 해제되며 할인 정보가 사라졌습니다. 다시 교육요금제로 돌려놓고 결제해야 합니다. 또한 이메일 변경 시 기존 이메일과 변경할 이메일 양쪽에 인증 코드가 전송되므로, 계정이 삭제되기 전에 미리 이메일 변경을 해두는 것이 안전합니다.

이렇게 써보세요교육요금제 할인 중이면 계정 삭제 전에 미리 이메일을 바꿔두세요.

대학원생 요금으로 제미나이 프로 저렴하게 이용 가능

함께한 선생님L과 함께한 선생님M 님이 대학원생 자격으로 제미나이 프로를 월 7300원대에 쓸 수 있다고 공유했습니다.

이렇게 써보세요대학원생이라면 제미나이 프로를 월 7300원대 요금으로 알아보세요.

자동화2

노션 버튼에 에이전트 메시지 전송 기능 추가

버튼 블록과 데이터베이스 버튼 속성에 프롬프트를 넣어 기본 에이전트에게 바로 메시지를 보낼 수 있습니다. 예를 들어 독서기록 페이지마다 버튼을 넣어 기록 완료 시 수업 아이디어를 추출하거나, 누가기록 데이터베이스에 버튼을 심어 생기부 초안을 작성할 수 있습니다.

이렇게 써보세요버튼 속성에 프롬프트를 넣으면 클릭 한 번으로 기본 에이전트 호출이 가능합니다.

Aside로 노션 자동화를 대신 처리

Aside를 노션에서 사용하면 자동화 설정도 대신 만들어준다는 점이 공유되었습니다.

이렇게 써보세요노션 자동화가 번거로우면 Aside를 활용해보세요.

AI1

Gemini 앱에서 개인 프로 계정은 아르곤(Gemini 3) 사용 가능

제미나이 앱 기준으로 개인 유료 프로 계정에서는 아르곤(Gemini 3)을 쓸 수 있다는 보고가 여러 명에게서 나왔습니다. 다만 플러스 플랜으로 낮춘 계정에서는 아르곤이 나오지 않았다는 사례도 있어, 플러스 플랜까지 지원되는지는 확인되지 않았습니다.

이렇게 써보세요제미나이 앱에서 아르곤이 안 보이면 계정이 프로인지, 플러스는 아닌지 확인해보세요.

임베드·연동1

에이전트로 브라우저 화면 조작을 자동 녹화하는 방법

에이전트가 브라우저를 조작하는 장면을 ffmpeg으로 녹화할 수 있습니다. 녹화 중에는 PC의 다른 조작이 어려우니 자기 전에 돌려두면 좋습니다. 커서는 Win32 API(SetCursorPos, mouse_event)로 실제 이동시키고, 이동 위치는 CDP로 요소 좌표를 받아 화면 배율을 보정해 계산합니다. 키보드 입력은 일반 글자는 CDP의 insertText로, 실제 키 입력이 필요하면 OS 레벨 SendKeys를 사용합니다.

이렇게 써보세요에이전트에게 Win32 API·CDP·SendKeys 방식을 구체적으로 지시하면 시행착오가 줄어듭니다.
