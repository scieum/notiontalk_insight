이번 주 오픈채팅방에서 가장 많이 오간 이야기입니다.

  1. AI 크레딧 체계 개편

    11월 2일부터 크레딧제가 적용되며 적용 시점, 소모량, 모델 선택 전략에 대한 질문이 여러 스레드에서 이어졌습니다.

  2. 노션 결제 할인과 요금제 혼란

    접속 차단 오류와 AI 첨부파일 문제가 동시에 제기되었지만 원인이 명확히 밝혀지지 않았습니다.

노션 AI 크레딧이 부담될 때 클로드 등 다른 AI로 노션 작업을 시키는 게 괜찮을까요?

이렇게 써보세요자주 쓰는 노션 페이지·DB는 AI의 상위 지침에 미리 적어두면 편합니다.

자동으로 반영되는 방법은 없고, 노션 데이터베이스 속성 값 변경을 트리거로 구글에 값을 입력하는 자동화를 직접 짜야 합니다.

이렇게 써보세요속성 값 변경을 트리거로 구글에 입력하는 자동화를 구성하면 됩니다.

공식 공지는 없었지만 여러 선생님이 동시에 같은 증상을 겪었고, 점심시간 내에 자연적으로 복구되었습니다.

기타

클로드나 코덱스로 작업하다가 컴퓨터를 바꿔도 이전 작업을 이어갈 수 있나요? 스킬은 어디에 저장되나요?

에이전트의 최상위 지침 파일, 스킬, 메모리 등은 기본적으로 로컬 경로에 저장됩니다. 업무 환경을 깃허브에 동기화해두면 다른 PC에서도 이어서 쓰기 쉽습니다. 다만 이는 지침·스킬·메모리에 한정된 이야기이고, 웹앱처럼 깃허브에 올려 배포하는 작업과 달리 로컬에만 남는 작업 산출물은 별도로 갈무리해야 합니다.

이렇게 써보세요에이전트 작업환경을 깃허브에 동기화하면 PC를 바꿔도 이어쓰기 쉽습니다.

노션 AI 브라우저 유즈 기능(playwright)

노션 AI에 브라우저 유즈 기능이 들어와 playwright 도구 사용이 가능합니다. 다만 사용자가 직접 보는 화면 없이 헤드리스 방식으로만 동작합니다. 노션 홈페이지에서 가이드 문서로 가는 길을 캡처·마킹해 가져오라고 시켜도 잘 처리합니다.

이렇게 써보세요노션 AI로 웹페이지 탐색·캡처가 가능하지만 화면은 직접 볼 수 없습니다(헤드리스).

노션 에이전트 사용량 크레딧 체계 개편 예고

모델을 자동 선택하면 비용을 줄이면서도 높은 퀄리티를 유지하도록 바뀝니다. 퍼스널 에이전트와 커스텀 에이전트 모두 크레딧으로 사용량이 관리됩니다. 스탠다드 크레딧은 매월 1500개로 모델을 오토로 설정하고 퍼스널 에이전트를 쓸 때 소모되고, 셀렉 크레딧은 매월 500개로 모델을 수동 선택하거나 커스텀 에이전트를 쓸 때 소모됩니다. 기존 유저에게는 11월 2일부터 적용됩니다.

이렇게 써보세요11월 2일부터 크레딧제가 적용되니 모델은 오토로 설정해 크레딧을 아끼세요.

노션 AI 오토 모드 크레딧 소모량 실사용 후기

오토 모드로 돌릴 경우 1500 크레딧 기준 30일간 하루 약 50크레딧 사용 가능하며, 노션 추정치로는 보통 작업 5개 정도면 소진됩니다.

이렇게 써보세요오토 모드 사용 시 하루 약 50크레딧, 작업 5개 정도로 소진됩니다.

노션 AI노트 원터치 실행 위젯 출시

노션에 새 위젯이 추가되어 AI노트를 원터치로 바로 실행할 수 있게 되었습니다.

노션 AI 딥시크 모델 가성비

labs.notion.com의 모델 비교 글에 따르면 딥시크 4.1 플래시는 오푸스·소넷급 모델과 해결율이 2% 정도만 차이나지만 비용은 오푸스의 1/10, 소넷의 1/4 수준입니다.

이렇게 써보세요노션 AI 토큰이 부족하면 딥시크를 기본 모델로 쓰고 중요한 작업만 상위 모델을 쓰세요.

기타4

노션 PDF 미리보기 기능 업데이트

저장된 PDF를 클릭하면 노션 내에서 화면을 보고 다운로드하거나 페이지로 추가하는 버튼이 생겼습니다.

이렇게 써보세요PDF 클릭 시 노션 안에서 바로 보기·다운로드가 가능합니다.

할인 결제 시도 중 오류로 요금제가 꼬일 수 있음

할인옵션으로 결제를 시도하다 오류가 나면서 결제가 취소되고 교육요금제까지 사라졌다가 겨우 복구한 사례가 있었습니다. 이후 할인옵션은 다시 뜨지 않았습니다.

이렇게 써보세요할인 결제 시도 중 오류가 나면 기존 요금제가 사라질 수 있으니 주의하세요.

체더스 공구 멤버 할인 추가 확인

작년 체더스 공구로 구독한 경우 무료 전환 다음날까지도 할인이 유지된 사례가 확인되었습니다.

이렇게 써보세요작년 공구 멤버라면 무료 전환 다음날까지도 할인 여부를 확인해보세요.

노션 연간 결제 시 달러 결제가 원화보다 저렴합니다

한화로는 25만2천원인데 결제 수단을 달러로 바꾸면 168달러(약 22만원)로 더 싸게 결제됩니다.

이렇게 써보세요결제수단을 달러로 바꾸면 원화보다 싸게 결제할 수 있습니다.

임베드·연동3

앱에 노션 DB를 로그인 방식으로 연결하기 쉬워짐

앱에 노션 데이터베이스를 로그인 방식으로 붙이는 설정이 예전보다 꽤 간편해졌습니다. 위치를 모르더라도 AI에게 물어보면 안내받을 수 있습니다.

이렇게 써보세요노션 DB를 앱에 로그인 방식으로 연결할 때 막히면 AI에게 바로 물어보세요.

노션 비즈니스 해지 시 요금제 변화 및 대체 수단

노션 비즈니스를 해지하면 교육플러스가 아니라 무료 계정으로 전환된다는 점을 공유했습니다. 대안으로 깃허브의 REA를 활용해 서버 없이 노션과 비슷한 개인 사이트를 제작 중이라고 밝혔습니다.

이렇게 써보세요노션 비즈니스를 해지하면 교육플러스가 아니라 무료 계정이 됩니다.

노션을 백엔드 DB로 연결해 앱과 양방향 연동

함께한 선생님B은 노션을 백엔드 DB처럼 활용하고 있습니다. 교무수첩의 진도관리와 출석은 별도 앱으로 만들어 입력을 쉽게 했고, 앱과 노션 양쪽에서 수정하면 서로 반영되도록 연동했습니다. 맥과 윈도우를 함께 쓰는 환경에서 노션을 매개로 데이터를 주고받는 용도로도 쓰고 있습니다.

이렇게 써보세요입력이 불편한 항목은 노션과 양방향 연동되는 전용 앱을 만들면 편해집니다.

협업2

학년부장의 노션 협업 참여 유도 방법

수업 자료를 많이 올리는 선생님께 3개월마다 1만원 선물쿠폰을 드리고, 메신저 내용을 전부 옮기지 않고 필요한 자료만 올려 참여도를 높였습니다.

이렇게 써보세요자료를 적극 공유하는 동료에게 소정의 보상을 주면 참여도가 올라갑니다.

노션 링크는 공유 후에도 수정 가능

노션의 장점으로 링크를 공유한 뒤에도 내용을 계속 수정할 수 있다는 점이 언급되었습니다.

이렇게 써보세요자료 링크를 미리 공유하고 내용은 노션에서 계속 업데이트하세요.

데이터베이스1

노션을 웹앱의 백엔드 DB로 활용

운영진이 러닝 챌린지와 독서 챌린지를 운영할 때 노션을 DB로 두고 별도 웹앱을 만들어 진행한 사례가 공유되었습니다.

이렇게 써보세요노션 DB를 웹앱 백엔드로 연결해 챌린지 운영에 활용해보세요.

노션 새 데스크톱 앱 베타가 공개되었고 메모리 문제를 크게 개선했다고 합니다. 데스크톱 앱 설치 후 설정-기본 설정에서 Desktop beta 옵션을 켜고 재시작하면 사용할 수 있습니다.

이렇게 써보세요노션이 무겁다면 설정에서 Desktop beta 옵션을 켜고 재시작해보세요.

이렇게 써보세요교무수첩 종결자 구매자는 복제제한이 풀려 있으니 새 학년도마다 복본을 만드세요.
